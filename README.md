# MLOPS-Time-prediction

The core objective of this machine learning model is to accurately predict the travel time between two locations.
It covers the full lifecycle from training and experimentation to deployment and continuous monitoring all organized into structured modules

### Step 1: Download and install the Anaconda distribution of Python
```sh
wget https://repo.anaconda.com/archive/Anaconda3-2022.05-Linux-x86_64.sh
bash Anaconda3-2022.05-Linux-x86_64.sh
```
